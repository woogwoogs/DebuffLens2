# DebuffLens2


Simple plugin to show debuffs anywhere you want and optionally with the name or short description of that debuff

![DebuffLens2 display modes](docs/images/debufflens2-modes.png)

From left to right: detailed, compact with names, and icon



Contains every debuff in the game. The dangerous ones are already set up, but each entry can be adjusted in the **Debuff Library**: enable/disable it, set its priority, change its short name, and configure its popup or sound preference.
